# Funnel Plots

There are two closely related components for stacked, tapering plots, these include:

-   `<Funnel>` - one trapezoid segment per row of data, narrowing from the widest at the top down to the narrowest at the bottom
-   `<Pyramid>` - a `<Funnel>` turned upside down, so the widest segment forms the flat base at the bottom and the narrowest sits at the top

<Canvas of={FunnelStories.Basic} />

## `<Funnel>` Component

The `<Funnel>` component plots one segment per row of data, each segment's width proportional to its
value. Every segment's bottom edge matches the next segment's top edge, so the shape narrows smoothly
from row to row - the last segment stays a flat-bottomed rectangle, since there's no further row for
its bottom edge to taper towards.

### Props

| Prop            | Type       | Default             | Note                                                                                                         |
| --------------- | ---------- | -------------------- | ------------------------------------------------------------------------------------------------------------ |
| **`category`\*** | `string`   | `null`               | The key of the field that contains the category/label for each segment.                                      |
| **`value`\***   | `string`   | `null`               | The key of the field that contains the value for each segment.                                                |
| `padding`       | `number`   | `2`                  | The gap, in pixels, to leave between each segment.                                                             |
| `sort`          | `boolean`  | `false`               | Should the segments be sorted by value (descending), rather than using the order of the data?                 |
| `inverted`      | `boolean`  | `false`               | Flips the funnel upside down, so the widest segment forms the flat base instead - use `<Pyramid>` for this.   |
| `colors`        | `string[]` | Derived from Theme   | Override the colours used for each category.                                                                  |
| `interactive`   | `boolean`  | `true`                | Whether the plot should be interactive. Setting this to false will disable tooltips from this plot            |
| `showInLegend`  | `boolean`  | `true`                | Whether the plot should feature in the legend or not.                                                         |

`<Funnel>` also accepts the usual chart-level props - `data`, `width`, `height`, `plotMargin`,
`theme`, `animationDuration`, `onClick`/`onMouseOver`/`onMouseOut` and so on - directly.

### Using Canvas

Like other plots, a `<Funnel>` can be rendered using an HTML Canvas instead of SVG by setting `useCanvas`.

### Sorting and data order

By default segments keep the order that they appear in the data - useful when your data already
represents the stages of a process in the right order. Set `sort` to order them by value (descending)
instead.

<Canvas of={FunnelStories.CustomOrder} />

### Negative values

A segment's width can't represent a negative value. If the dataset contains negative values in the
`value` field, they're treated as `0` and a `W009` warning is logged - see [the `<StackedDonut>`
docs](/docs/radialcharts-stackeddonut--docs) for the same behaviour on the polar equivalent of this
chart.

## `<Pyramid>` Component

The `<Pyramid>` component is a `<Funnel>` turned upside down. It accepts the same props as `<Funnel>`,
except `inverted` - a Pyramid, by definition, is always inverted, so it isn't exposed.

<Canvas of={FunnelStories.AsPyramid} />

```jsx
<Pyramid category="stage" value="count" sort={true} />
```
