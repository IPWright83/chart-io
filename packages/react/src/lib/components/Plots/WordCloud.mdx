# WordCloud Plots

The `<WordCloud>` component sizes each word in a flat dataset's `category` field proportionally to
`value`, and packs the words - largest first, working outward from the center - into the available
space without overlapping. It's a self-contained chart - like `<Treemap>`/`<CirclePacking>`, it accepts
chart-level props like `data`/`width`/`height` directly, since it only ever has a single plot.

<Canvas of={WordCloudStories.Basic} />

## `<WordCloud>` Component

### Props

| Prop            | Type       | Default             | Note                                                                                                          |
| --------------- | ---------- | -------------------- | -------------------------------------------------------------------------------------------------------------- |
| **`category`\*** | `string`  | `null`               | The key of the field that contains the text for each word.                                                     |
| **`value`\***   | `string`   | `null`               | The key of the field that contains the size for each word.                                                     |
| `minFontSize`   | `number`   | `12`                  | The font-size, in pixels, given to the word with the smallest value.                                            |
| `maxFontSize`   | `number`   | `60`                  | The font-size, in pixels, given to the word with the largest value.                                             |
| `padding`       | `number`   | `2`                   | The gap, in pixels, kept clear around every word, so neighbouring words never visually touch.                  |
| `fontFamily`    | `string`   | Derived from Theme   | The font family words are rendered in.                                                                          |
| `rotate`        | `boolean`  | `false`               | Should alternating words be rotated 90 degrees, for a more traditional word cloud look?                        |
| `colors`        | `string[]` | Derived from Theme   | The set of colors to cycle through for each word.                                                               |
| `measureText`   | `function` | A `<canvas>`-based measurer | Measures the pixel dimensions a word would take up at a given font-size - see below.                     |
| `interactive`   | `boolean`  | `true`                | Whether the plot should be interactive. Setting this to false will disable tooltips from this plot.             |
| `showInLegend`  | `boolean`  | `false`                | Whether the plot should feature in the legend or not.                                                           |

`<WordCloud>` also accepts the usual chart-level props - `data`, `width`, `height`, `plotMargin`,
`theme`, `animationDuration`, `onClick`/`onMouseOver`/`onMouseOut` and so on - directly, since it's a
self-contained chart.

> **Note**: Every value in the `category` field should be unique in the data. If your data has multiple
> rows for the same word, aggregate it first.

### Placement order

Words are always placed largest-first, working outward from the center along an Archimedean spiral -
unlike `<Treemap>`/`<CirclePacking>`'s `sort`, this isn't a cosmetic option: a spiral layout only
produces a tightly packed cloud when the most prominent words claim the center first, so there's no
`sort` prop to turn it off.

If a word's bounding box can't be placed anywhere in the available space without overlapping another
word - most often because there are too many words, or `minFontSize`/`maxFontSize` are set too large
for the chart's `width`/`height` - it's dropped from the layout entirely and a `W010` warning is
logged. Widen the chart, shrink the font-size range, reduce `padding`, or trim the dataset to fix it.

### Using Canvas

Like other plots, a `<WordCloud>` can be rendered using an HTML Canvas instead of SVG by setting `useCanvas`.

<Canvas of={WordCloudStories.Canvas} />

### Rotated words

Set `rotate` to alternate every other placed word between horizontal and vertical, for the more
traditional word cloud look:

<Canvas of={WordCloudStories.Rotated} />

```jsx
<WordCloud category="word" value="count" rotate={true} />
```

### Custom text measurement

By default, each word's rendered width/height is measured with a detached `<canvas>` 2D context - the
standard way to measure text in a browser. If `<canvas>` isn't available in your environment, or your
font needs custom letter-spacing/loading behaviour accounted for, pass your own `measureText` matching
the signature used internally by `computeWordCloudLayout`, exported from `@chart-io/core`:

```jsx
import { computeWordCloudLayout } from "@chart-io/core";

<WordCloud
    category="word"
    value="count"
    measureText={(text, fontSize, fontFamily) => {
        // Return the pixel dimensions `text` would take up at `fontSize`/`fontFamily`
        return { width: text.length * fontSize * 0.6, height: fontSize * 1.1 };
    }}
/>
```
