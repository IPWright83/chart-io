# Radar Plots

The `<Radar>` component plots one closed polygon per field in `ys`, connecting a point per
category around a shared angular scale - useful for comparing several entities across multiple
quantitative variables. Unlike `<Pie>`/`<Donut>`/`<StackedDonut>`, a Radar plot needs an
`<AngleAxis>` (spokes/category labels) and a `<RadiusAxis>` (concentric rings/value labels) to
provide its angular and radial scales, similar to how `<Line>` needs an `<XAxis>`/`<YAxis>` within
an `<XYChart>`. All three should be used within a `<RadialChart>`.

## `<Radar>` Component

### Props

| Prop            | Type       | Default             | Note                                                                                                          |
| --------------- | ---------- | -------------------- | -------------------------------------------------------------------------------------------------------------- |
| **`category`\*** | `string`   | `null`              | The key of the field that contains the category/label for each point (must match the `<AngleAxis>` field).     |
| **`ys`\***      | `string[]` | `null`               | The keys of the fields to plot, one series (polygon) per field.                                                 |
| `colors`        | `string[]` | Derived from Theme   | Override the colours used for each series.                                                                      |
| `fillOpacity`   | `number`   | `0.15`               | The opacity of each series' filled area.                                                                        |
| `markerRadius`  | `number`   | `4`                  | The radius, in pixels, of each vertex marker.                                                                   |
| `interactive`   | `boolean`  | `true`                | Whether the plot should be interactive. Setting this to false will disable tooltips from this plot              |
| `showInLegend`  | `boolean`  | `true`                | Whether the plot should feature in the legend or not.                                                           |

### `<AngleAxis>` and `<RadiusAxis>`

`<AngleAxis fields={[category]} />` draws a spoke and label for each category around the plot, and
`<RadiusAxis fields={ys} />` draws concentric rings with value labels. Both register the underlying
d3 scales that `<Radar>` reads, the same way `<XAxis>`/`<YAxis>` do for `<Line>`.

### Using Canvas

Like other plots, a `<Radar>` can be rendered using an HTML Canvas instead of SVG by setting `useCanvas`.
