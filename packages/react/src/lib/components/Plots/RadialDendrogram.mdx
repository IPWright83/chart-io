# RadialDendrogram Plots

The `<RadialDendrogram>` component is the polar equivalent of [`<Dendrogram>`](/docs/plots-dendrogram--docs) -
the same tree of nodes and links built from `categories`, radiating outward from the center instead of
growing left-to-right, with every leaf aligned at the same radius. It's a self-contained chart - like
`<Dendrogram>`, it accepts chart-level props like `data`/`width`/`height` directly, since it only ever
has a single plot.

<Canvas of={RadialDendrogramStories.Basic} />

## `<RadialDendrogram>` Component

### Props

Identical to [`<Dendrogram>`](/docs/plots-dendrogram--docs#dendrogram-component) - `categories`, `value`,
`nodeRadius`, `labels`, `sort`, `colors`, `interactive`, `showInLegend` and `buildHierarchy` all mean
the same thing here, just laid out radially instead of left-to-right.

### Zooming

Just like `<Dendrogram>`, set `zoomable` (and optionally `breadcrumb`) to let a click on a node zoom in
and refocus on its subtree:

<Canvas of={RadialDendrogramStories.Zoomable} />

```jsx
<RadialDendrogram categories={["continent", "country", "sector"]} value="gdp" zoomable={true} breadcrumb={true} />
```
