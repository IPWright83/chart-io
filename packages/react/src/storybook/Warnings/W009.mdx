# W009 Negative Values Not Supported

> `Negative values in the ${value} field aren't supported by <${componentName}> and have been treated as 0.`

This warning indicates that the dataset contains one or more negative values in the field used for a
chart's `value`.

## Cause

Some charts size each element using an angular span, a rectangle's area, a font-size, or similar - none
of which can represent a negative size. This includes hierarchical charts (e.g. `<StackedDonut>`,
`<Treemap>`, `<CirclePacking>`, and others built on the same shared hierarchy) as well as `<WordCloud>`.
Negative values are treated as `0` so the chart still renders, rather than producing a broken or
degenerate layout.

## Fix

Filter out or clamp negative values in your dataset before passing it to the chart, if the `0`
treatment doesn't already give you the result you want.
